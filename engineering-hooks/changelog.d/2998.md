- `hold_guard.py`, a PreToolUse hook on Bash: refuses a `git push` to a branch whose PR (or the issue it closes) carries `loop:hold`, and a PR created (`gh pr create`, or a POST to `.../pulls`) for a held issue, naming the hold and who set it; removing the label lifts both. A hold sent as a message loses the race with the turn in flight, so the label is the hold (#2998)
