- engineering-loop: a host's heavy wrapper, a command prefix (a `systemd-run --user --scope` with CPU and memory limits) set as the `heavy_wrapper` key of the loop's new host config, `${XDG_CONFIG_HOME:-~/.config}/engineering-loop/host` (`key = value` lines, read by `approvals.py`'s `host_config()`), runs every heavy step under it: each gate step of `local-ci` and `land`, the `pre_land` check, `mutate.py`'s test runs and the new `approvals.py heavy <command>`, which worker.md's and verifier.md's recipes use. Without the key nothing changes; a prefix that can't run says so once and runs the step unwrapped. A step now runs in a session of its own, and a stop or exception kills its whole process group, so a wrapped step never outlives a stopped run (#1092).
