- engineering-loop: a host's heavy wrapper, one command prefix in `${XDG_CONFIG_HOME:-~/.config}/engineering-loop/host` (`heavy_wrapper = <prefix>`, a `systemd-run --user --scope` with CPU and memory limits), runs every heavy step under it: each gate step of `local-ci` and `land`, the `pre_land` check, `mutate.py`'s test runs and the new `approvals.py heavy <command>`, which worker.md's and verifier.md's recipes use. Without the file nothing changes; a prefix that can't run says so once and runs the step unwrapped. A step now runs in a session of its own, and a stop or exception kills its whole process group, so a wrapped step never outlives a stopped run (#1092).
