- engineering-loop: the host gate has `GATE_SLOTS` heavy slots (`gate.1.lock` to `gate.<N>.lock`), a third of the host's cores by default and at least 1, and `local-ci`, `land` and `mutate.py` take the first free one through one function (`approvals.take_slot`), waiting only when all are held; `LOOP_GATE_SLOT_HELD` names the slot actually held, `GATE_SLOTS=1` keeps one gate at a time, and a runner's `GATE_JOBS` share is at most the cores divided by the slot count. A local-ci record is now written whole and renamed into place, so two gates on one tree and command never leave it torn; a land's gate step takes a freed slot ahead of a waiting PR gate, through a shared lock on `gate.land.lock` that a PR gate yields to (#1138). A run under any `gate.<n>.lock` takes no second slot, whatever its own `GATE_SLOTS`; this repo's `mise run test` wrapper takes its slot through `take_slot`, so it too yields to a waiting land; a failed record write leaves no `.partial` file.
