- engineering-loop: a spec's `## Acceptance` holds a `### Before merge` list, which the proof and the verifier run on the PR branch, and an `### After merge` list of only the checks that need the merged default branch or a deployed environment, which step 9 runs instead of a second run on the owner's instance; a flat list reads as all Before merge, and the verifier lists After merge lines without counting them (#1153, #949). The `to-spec` template and `github-project-board-setup`'s issue template carry both lists.
