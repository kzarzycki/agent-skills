- engineering-loop: each head's tests run once. The worker's push runs `approvals.py push-gate`, which runs loop.md's `Affected tests: <command> <base>` line (the project's lint and the tests its change affects against that base; in a shallow clone the base is fetched first) and `mise run check` without it; that run is a draft head's gate, CI's PR run (or `local-ci` with `ci: false`) runs the same selection once the PR is ready as the gate of record, which the verifier reads instead of rerunning, and the merge queue runs every part in full (#1174).
