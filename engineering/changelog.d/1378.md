- `land` writes the `land` event of each PR's branch (`waiting` at every poll of `--wait`, `ok` when merged, `failed` with the log comment's URL when evicted, `needs-owner` at the owner's go or the 2-hour ceiling) and clears the merged branch's refs a grace later, so a native lead blocks on it with `events.py wait land <branch>`; a failed write changes none of `land`'s exit codes (#1378).
