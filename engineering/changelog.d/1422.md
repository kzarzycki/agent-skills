- engineering-loop: narrowed gates by default (#1422). A project whose loop.md names an `Affected tests:` command (its
  selector plus its cheap whole-repo lint and type checks, as one task) now has every gate run that command: each PR
  head, draft or ready (`approvals.py affected-tests`, which takes `--base <rev>` for a PR's base SHA or a push's
  previous main tip, and runs the full `mise run check` for a base git can't resolve), and `land`'s batch gate, which
  selects over the batch's combined diff against the base tip it merges onto. Under `ci: false`, `local-ci --record`
  records a narrowed pass against the merge base, which `check merge` takes; a narrowed pass is keyed by command and
  base and never stands for a full one. The line `Gate: full` returns every gate to the full check. Without the
  `Affected tests:` line nothing changes, and `check build` says in one line that every gate runs the full check. A
  project adds its `Affected tests:` command, and from the project template its CI's push and ready runs of
  `affected-tests --base` and the nightly full-suite workflow that calls `nightly.py red`; a project with
  `gate_steps` keeps its steps.
