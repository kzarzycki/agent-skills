- `acceptance.py` parses a sh or bash check with `<shell> -n` before running it, and reports one that does not parse as `FAIL ... does not parse`. Under `set -e`, bash 3.2 (macOS's /bin/bash) runs the EXIT trap on a syntax error and exits with the trap's status, so a broken check could pass (#1545). The shell is the shebang's, or the one `env` runs (its `-S` string split as `env` splits it, assignments skipped). The shebang's flags stay off the parse, and a bash check that turns extglob on (`shopt -s extglob`, `-O extglob`) also parses with `-O extglob`, passing when either grammar parses.
