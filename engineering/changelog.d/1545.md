- `acceptance.py` reports a check that bash stopped on a syntax error as `FAIL ... does not parse`, whatever its exit code. Under `set -e`, bash 3.2 (macOS's /bin/bash) runs the EXIT trap on a syntax error and exits with the trap's status, so a broken check could pass. The runner reads the line bash writes for it (`<check>: line <n>: syntax error`) from the check's stderr, which still passes through (#1545).
