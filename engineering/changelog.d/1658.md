- engineering-loop: `land` can hand PRs to a Mergify merge queue (`land.queue: mergify` in the policy's `land:` section): it posts the `land` status on each candidate's head and adds `loop:queued`, takes no lock and runs no host gate, and Mergify tests each batch in CI and squash-merges it. A PR Mergify dequeues (`loop:dequeued`) is evicted back to draft; a bare `land` writes the `Landed` trail of the PRs it merged. Every call is REST, so a cloud session lands this way with no signing key. Off until a project sets the key (#1658).
