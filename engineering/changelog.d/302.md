- `omnigent_agent.py` starts sessions on the server of the calling session (`RUNNER_SERVER_URL`), so a child sits beside its parent, instead of config.yaml's `server:`, which is only a default on a machine logged in to several servers. `OMNIGENT_SERVER` overrides it; with neither, the one login in `auth_tokens.json` is used, and several logins refuse, naming `OMNIGENT_SERVER` (#302).
