- loop.md's settings are a TOML block that `approvals.py` reads with Python's `tomllib`, in place of the line language its regular expressions read: a rule is keys (`labels`, `paths`, `always`, `verifier`), never words, so a path such as `docs/verifier.md` can no longer read as the `verifier` term, and a section or key the schema doesn't know or a value of the wrong type is refused, naming the key. A value names a thing, never a rule in words: the spec policy is `[spec] auto`, an array of the kinds it approves or `true`, not a phrase. SKILL.md § Settings holds the schema and why TOML: typed, read by the standard library on Python 3.11 and later, and readable and editable by hand. Shipped scripts now need Python 3.11 (#344).
