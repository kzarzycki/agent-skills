- engineering-loop: with loop.md's `carry_over_main` section (`except: <globs>`), a clean merge of main into a PR head keeps the head's verdict and `local-ci` record: the merge's first parent is the verified head, its second is on main, its tree is `git merge-tree`'s, and main's changes touch none of the PR's files and no except glob. `local-ci <pr>` posts the carried record, `check merge` and `land` print one line naming both heads, and a signed-squash `land` squashes the clean merge of a head behind main's tip. A conflict, an evil merge, an overlap, a touched except path or any git error carries nothing; without the section nothing changes (#373).
