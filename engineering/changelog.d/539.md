- engineering-loop: `approvals.py local-ci` keys a pass by tree and gate env instead of by commit, so a rebase, reworded or cherry-picked commit with the same tree reuses it, and the posted comment names the commit the pass ran on. It publishes each pass as a `local-ci/<key>` commit status on the head, and a pass a writer or the running account published there counts in any clone, so `local-ci <pr>`, `check queue`, `batch` and `check merge` on one host accept a gate run on another. `local-ci --record` on a checkout with changes runs the check and records nothing, so it is the gate while iterating and its clean green run records itself (#539, #635).
