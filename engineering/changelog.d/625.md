- engineering-loop: `approvals.py local-ci` (with or without `--record`), unless it already leads its own session, runs again in a new one with stdin from /dev/null and follows its log, exiting with its exit code, so a harness that kills the caller's process group no longer takes the check down unrecorded. The log, pid and exit code sit beside the record under the git common dir; a second `local-ci` on a running head follows that run, and `local-ci --status <head>` reports running, passed or failed. The pid file holds the run's start time beside its pid, so a pid the system has reused reads as gone. The check's stderr and a refusal arrive on the caller's stdout, in the followed log (#625).
