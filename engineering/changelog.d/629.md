- engineering-loop: `scripts/mutate.py` is the one mutation check, run by the worker over its own production changes before it reports and by the verifier in review, instead of a harness each pass writes. It refuses a tree with changes, applies each patch alone, runs the test command, restores the tree and checks it is clean, and on SIGINT or SIGTERM restores the applied patch before it dies; its log starts with the head and its command line, then `<patch>: exit <n> killed|survived` per patch. Exit 0 when every patch is killed, 1 when one survives, 2 on a refusal, a patch that doesn't apply or a failed restore. A worker's simplification (YAGNI, `ponytail:`) changes how a spec item is built, never whether: narrowing one is a question to the lead, and the report carries a fixed `Spec deviations:` line. A `ponytail:` that narrows an approved item is a finding, and the lead fixes each deviation or takes it to the owner before a verifier starts, then writes the PR body's `Spec deviations:` line. This repo's `mise run check` runs the three gates CI runs (#629, #630).
