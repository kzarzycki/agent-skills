- engineering-loop: `approvals.py check build <pr>` refuses an issue that another open PR also closes (a closing keyword, or `Implements` under a `signoff` rule), naming that PR and its branch, so a second build of the same issue stops before its verifier, gate and merge queue run. One `gh pr list` call per check, only for a PR that closes an issue; an issue of another repo with the same number is a different issue; `Part of` links don't count, since several PRs may build on one issue (#644).
