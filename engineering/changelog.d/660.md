- `agent-hygiene`: host hygiene for dev accounts where coding agents work, moved from dotagents' `disk-hygiene` script with its tests. It clears merged worktrees, tool caches, idle environments and dead Omnigent terminals; a scheduled round settles the routine cases it keeps (tagging a merged worktree's unpushed work locally before removing it) and passes on only what needs the owner, once (#660).
