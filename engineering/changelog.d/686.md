- engineering-loop: loop.md's `loop.pre_land: <command>`, parsed as `gate` is, is a project check `land` runs for each candidate before batching it, in the batch worktree at the base's tip with `LAND_HEAD` and `LAND_BASE` set, so the base's version of the check judges every PR, such as one refusing a branch forked before a restructuring. A non-zero exit leaves that PR out of the batch with one comment per head holding the check's output; it is not red, so it is neither evicted nor turned back to draft, and a named `land <pr>` exits 1. Without the key nothing runs (#686).
