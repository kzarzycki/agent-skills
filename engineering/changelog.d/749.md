- engineering-loop: `approvals.py land` stopped by SIGTERM or SIGHUP (a killed process group, a harness timeout) releases the landing lock on its way out and exits 128 plus the signal, so the next land no longer waits up to 2 hours for it to go stale. A stop that arrives while the lock is pushed is covered too, and a second stop (`uv run` forwards the signal Python already got) is ignored so it can't kill the release. SIGKILL still leaves the lock to be broken as stale (#749).
