- engineering-loop: `approvals.py` and `mutate.py` hand the commands they start (the gate, `pre_land`, `--test`) the caller's environment at startup, not the uv script environment: a `VIRTUAL_ENV` equal to `sys.prefix` is dropped with its `bin` on `PATH`, and uv's `UV_RUN_RECURSION_DEPTH` count is undone, so a tool that follows `VIRTUAL_ENV` checks the project against the project's packages. A `VIRTUAL_ENV` of another path (the script started by an interpreter directly) stays; nothing is reconstructed, so under `uv run`, which replaces the caller's value before the script starts, the gate sees none (#787).
