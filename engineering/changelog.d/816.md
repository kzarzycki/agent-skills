- engineering-loop: `land` runs in a cloud session (Claude Code's `CLAUDE_CODE_REMOTE=true`) with loop.md's `land` section, which gains `where` (`host`, the default, `cloud` or `both`; refused elsewhere before any PR is read) and `signing_key_env`, the variable holding a landing key listed in the allowed signers: each squash is signed and verified with it through `ssh-keygen`, over the session's own key and signer, from a mode-0600 file removed however the land ends; a missing, empty or unlisted key is refused and never printed (#816). In a cloud session a PR lands only where the section says `merge_queue: false`, the project's word that its base requires no merge queue, since REST says neither whether a PR is queued nor whether classic branch protection requires a queue.
