- Risk as a board field: the board template (`github-project-board-setup`) adds a single-select `Risk` field (`Low`, `Medium`, `High`) shown beside `Priority`; `board.py field <issue or PR> <field> <option>` sets any single-select field by name; `approvals.py check merge` sets a PR's `Risk` to `High` beside `risk:high`, else to the verifier's `Risk:` word, and adds `risk:high` when the field already says `High`, never lowering it. The label stays the merge check's only input, and a board it can't read or set is an output line, never a failure (#929).
