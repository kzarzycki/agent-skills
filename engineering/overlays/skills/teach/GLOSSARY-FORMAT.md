# GLOSSARY.md Format

`GLOSSARY.md` is the canonical language of the teaching workspace. Lessons, exercises and learning records use its terms. Compressing a concept into a tight definition is itself evidence the user understands it.

```md
# {Topic} Glossary

{One or two sentences on what the glossary covers.}

## Terms

**Progressive overload**:
Systematically increasing the demand on a muscle over time, via load, volume, or intensity.
_Avoid_: Pushing harder, levelling up
```

- Add a term only once the user can use it correctly; the glossary records compressed knowledge, it is not a dictionary to learn from.
- Pick one word per concept and list the others under _Avoid_.
- One or two sentences defining what the term is, not how to do it, using the glossary's own terms where they apply.
- Group under subheadings when clusters emerge.
- Resolve loose field usage explicitly: "In this workspace, 'set' always means a working set."
- Revise definitions in place as understanding deepens.
