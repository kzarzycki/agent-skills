# experimental

A staging ground for skills that aren't settled yet.

**The contract:** anything in this plugin is under active iteration. Interfaces,
behavior, and the skill set itself may change, break, or be removed at any time,
and versions here are **not** held to the stability or compatibility guarantees
of the other plugins. Install it knowing that — and pin a commit if you need
something here to stay put.

Skills graduate out of `experimental` into a stable plugin once their shape has
settled.
