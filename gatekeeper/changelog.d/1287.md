- `land --wait` on a base whose ruleset requires GitHub's merge queue is now `land` with no flag: it enqueues each PR, prints its queue position once and exits 0, and never sleeps or reads the queue again, so a waiting land no longer spends GraphQL quota; a later `land <pr>` still reads a removed entry (one comment, one enqueue, draft on the second red). The Mergify and local-queue waits are unchanged (#1287).
