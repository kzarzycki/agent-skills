- gatekeeper: gatekeeper.md's `select` (`build_inputs`, optional `checks`) cuts `affected-tests` by build input: a change whose every file is non-product (docs, prose, `.agents/`, `.claude/`, the pack's `apm.yml` and lock, or a check's paths) skips the `Affected tests:` command and runs only the checks it touches, so a docs, skills or pack-bump PR skips the build and the suites; a path matching neither list counts as a build input (#1638).
