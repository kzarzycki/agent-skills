- gatekeeper: gatekeeper.md's `select` (`build_inputs`, optional `checks`) cuts `affected-tests` and the narrowed gate (`local-ci --record`, with or without `--base`, and `local-ci <pr>` under `ci: false`) by build input: a change whose every file is non-product (docs, prose, `.agents/`, `.claude/`, the pack's `apm.yml` and lock, or a check's paths) skips the `Affected tests:` command and runs only the checks it touches, so a docs, skills or pack-bump PR skips the build and the suites; a moved file counts under both its names, and a path matching neither list and the policy files count as build inputs, and a project whose tests read a file under `docs/`, `.claude/`, `.agents/` or any `.md` lists it in `build_inputs`; the change is the head's commits since the base (`local-ci <pr>` reads the PR's head from any checkout), and uncommitted or untracked changes, a diff git can't list, or `select` without `build_inputs` cut nothing; a narrowed record of a non-product change is keyed by the checks it ran (#1638).
