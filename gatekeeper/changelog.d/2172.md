- gatekeeper: `land --wait` waits as long as the project's `land.wait` (a duration such as `2h` or `4h30m`; default 2 hours as before), so a project whose queue's checks run longer than 2 hours no longer has its land stopped while the PR is still being checked; the stop message names the configured time. A stop on a PR a merge queue holds, or whose checks run, leaves its `land` event `waiting` and writes no `needs-owner`; `needs-owner` stays for one nothing is moving. The landing lock's staleness stays 2 hours whatever `land.wait` is. `breakglass.max_age` shares the duration parser, so it also takes minutes and `1d12h` forms (#2172).
