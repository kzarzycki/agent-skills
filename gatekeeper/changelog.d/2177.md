- gatekeeper: `approvals.py rerun-tests <failed-tests.json> --red <head> [--base <rev>]` is a red run's one rerun (R5): from the red run's failed test ids, its head and its base it recomputes the selection and runs loop.md's `Affected tests:` line against `<head>` when the change since the red reselects every failed test (the failed tests plus what the fix reaches), else against the base (the red run's whole selection, in its order); a failed test that passes there is named a flake, red again stays red, and one line says which case and why. Never the failed tests alone, and nothing is stored (#2177).
