- gatekeeper: a claim names the Omnigent session that holds the issue (#2324). Under Omnigent, `check build`'s `Assigned:` record adds `Session: <server>/c/<lead's session id>` (the lead's, also when a worker or verifier runs it) and the issue's `Session` issue field is set to the same link with `setIssueFieldValue`. The field is optional and the account's owner creates it: without it, or where GitHub refuses GraphQL, the run makes one lookup and prints one line, and the claim, the record and the exit code are as before; a refused write is one line. Outside Omnigent nothing changes.
