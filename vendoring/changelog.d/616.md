- vendoring: the first release. The `vendoring` skill holds the capability-pack tool (`scripts/capability_pack/`, formerly `tools/capability_pack/`) and the engineering package's maintenance routine (`ROUTINE.md`, formerly `engineering/ROUTINE.md`); `update-delta-audit` joins it from `experimental`. The tool holds a pack to the upstream its `upstream.yml` declares, not to one built-in repository, and reads the upstream skills folder from its `skills_path`, so a fork can vendor a package from this repository by lock and keep its own overlays; `scripts/vendor.py` runs the tool with its own Python and PyYAML through `uv run`, so an installed copy needs no Python project around it. `ROUTINE.md` states the method only; a project gives its branch, gates, landing and release rules as values for the routine's slots (#616).
